# 图书管理系统

Java 课程设计：基于 Swing + H2 数据库的桌面图书管理系统。

## 功能

- 用户登录与权限：区分管理员和店员
- 左侧导航栏：管理员与店员显示不同功能入口
- 数据概览：查询、导入导出、展示书籍列表、销售统计图表（柱状图 / 饼图），使用子标签页切换
- 库存管理：添加、修改、删除、多条件搜索定位、展示书籍列表
- 库存预警：库存低于 10 的图书在表格中高亮显示
- 图书销售：按 ISBN 销售，自动扣减库存，使用 BigDecimal 精确计算金额；ISBN 框支持回车查询
- 销售记录：每次销售自动记录，支持查看历史销售明细、总笔数与总金额
- 数据导入导出：支持 Excel（.xlsx）和 CSV 导入，Excel 导出图书数据
- 统计报表：按日 / 月 / 年统计销售额、销量，使用 JFreeChart 生成柱状图和饼图
- 用户体验：价格 / 库存输入框限制数字输入；双击表格行回填表单；表格列宽自适应；面板切换保留表单状态；登录框和导航栏带图标
- 数据持久化：H2 嵌入式数据库，程序重启后数据不丢失

## 技术栈

- Java 17+
- Maven
- Swing
- H2 Database
- JDBC
- JFreeChart

## 运行方式

```bash
mvn clean package
java -jar target/book-management-system-1.0-SNAPSHOT.jar
```

## 管理员界面

- 数据概览：查询、导入导出、展示书籍列表、销售统计图表（柱状图 / 饼图）
- 库存管理：添加、删除、修改、多条件搜索定位、展示书籍列表
- 图书销售：输入 ISBN 与购买数量进行销售
- 销售记录：历史销售明细

## 店员界面

- 图书销售
- 销售记录

## 架构

- `entity`：实体层
- `repository`：数据访问层
- `service`：业务逻辑层
- `ui`：表现层（Swing）
- `util`：工具类
